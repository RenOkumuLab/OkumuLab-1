# OkumuLab 1 開発メモ（v2.0.0）

Labium（フルーパイプ。v2.0.0 から Prinzipal 8' と Gedackt 8' の 2 つのストップ）の物理モデルを、C++ / JUCE 8 の VST3 とスタンドアロンにしたものです（Windows x64、macOS、Linux。macOS は Audio Unit も）。画面は Web の表示部品（Windows は WebView2、macOS は WKWebView、Linux は WebKitGTK）と Three.js で、C++ の音源の物理状態（ジェット、管内の定在波、壁の振動）をそのまま描きます。

このファイルは開発中の記録です（物理モデルの中身、版ごとの変更、検証の結果）。文中の `test_out/`（試験の記録と試聴用 WAV）と `tools/pluginval/` はリポジトリに含めていません。使い方とビルドの手順はリポジトリ直下の `README.md` にあります。

- 製品名 **OkumuLab 1**、バージョン **2.0.0**、メーカー **OkumuLab**
- プラグインコード `OkmL` / `Lbm1`。以前の「OkumuLab 1」v0.2.2〜0.4.0（`OkmL` / `Ok01`）とは別のプラグインとして扱われるので、それらを使っているプロジェクトには影響しません。
- v0.5.0（手順3・4）からの追加：**Mallet モード**（パイプを硬いマレットで叩く）、**WIND モードの風圧の見直し**（弱い風での音量）、**物理的な残響**（教会の身廊を計算）、**手順5**（Lab の変調の全項目、変調マトリクス、実験レシピ、最適化、pluginval）。
- v0.6.1：MIDI CONTROLLER のつまみ 5「Wind pressure」の中身を、それまでの Bellows（ふいご）パラメータにしました。1.00 = 500 Pa、0.00〜5.00 です（下の「Wind pressure（v0.6.1）」）。
- v0.6.2：DAW の中でも 3D の画面（パイプが回る画面）が開くようにしました。画面の見出しから説明の文字を除きました（下の「画面と DAW（v0.6.2）」）。
- v0.6.3：プラグインの中の人名を除きました。レシピ 1 の名前を「Prinzipal 8'」にし、その説明文からも除き、風圧つまみの緑の帯の説明は「Baroque organ examples」にしました。画面左上のロゴを「OkumuLab 1」の表記にしました（予備のネイティブ画面も同じ）。
- **v1.0.0**：Prinzipal の寸法を文献と照らし合わせ、初期値の音を含めて「ビリビリ」と聞こえていた音を直しました（下の「Prinzipal の寸法の見直し（v1.0.0）」）。風圧の基準 500 Pa、つまみ・範囲・初期値・レシピの値は同じです。右の状態表示の GAS は Gas つまみが AIR 以外のときだけ点灯し、起動時の画面のロゴは「OkumuLab 1」の表記です。

  2. 手順1のモデルでは Prinzipal がガンバやハーモニカのように鋭く聞こえたので、その原因を発音・励振の物理（ジェット、ラビウム、管の損失と放射）で調べて直しました。ジェットが歌口を渡るあいだに広がることと、管の両端の放射損失を、文献の式どおりに入れました。音を後から加工する処理は使っていません（下の「発音・励振メカニズムの見直し（v1.1.0）」）。

  macOS 版（VST3、Audio Unit、スタンドアロン）と Linux 版（VST3、スタンドアロン）も同じソースから作ります（下の「macOS 版と Linux 版」）。

- **v2.0.0**：2 つ目のストップ **Gedackt 8'**（木製の停管）を加えました。寸法・切り上げ・端補正・壁の損失・木材は文献の値です。Open/Stopped は栓の抜き差しで、初期値は Stopped 100 %、画面でも栓が抜けていきます。歌口の側面の髭（Seitenbärte）と半円形の切り上げ、Mallet モードの木の板の振動モデルも新しく作りました。上のバーの実験レシピのメニューを、同じ場所・同じ見た目のストップ選択にしました。音域は両方のストップとも MIDI 24〜96 で、それ以外の鍵は鳴りません（下の「Gedackt 8'（v2.0.0）」）。

## ビルド

必要なもの：Visual Studio 2022 以降（Build Tools 可）の「C++ によるデスクトップ開発」と「Windows 用 C++ CMake ツール」。CMake と Ninja は Visual Studio 付属のものを使います（`build.bat` は、両方が入っている最新の Visual Studio を選びます）。

```
build.bat          VST3 + スタンドアロン + 試験（Release）
build.bat dsp      DSP コアと labium_check だけ（JUCE なし、数十秒）
```

- JUCE のファイル名が長いため、**短いパスに置いてビルド**してください（例：`C:\dev\OkumuLab1`）。
- 最初のビルドは JUCE ごとコンパイルするので数分かかります。`web/` だけを変えたときは zip の作り直しとリンクだけです。
- C ランタイムは静的リンクです。配布先に Visual C++ 再頒布パッケージは要りません。
- リソースコンパイラの依存関係スキャン（cmcldeps）は切ってあります（`CMakeLists.txt` 先頭）。日本語の Windows では cl.exe の「メモ: インクルード ファイル:」が rc.exe のコマンドラインを壊し、再構成のあとに RC1107 で止まったためです。
- AVX2 の内側ループ（`SimdAvx2.cpp`）だけを `/arch:AVX2` でコンパイルし、実行時に CPU を調べて使います。AVX2 のない CPU では SSE2 版が動きます。

## インストールと使い方

- **VST3**：Releases の zip にある `OkumuLab 1.vst3` フォルダを `C:\Program Files\Common Files\VST3\` にコピーし、DAW でプラグインを再スキャンします（コピーには管理者権限が要ります）。1 ファイルの形で入れる場合は、中の `Contents/x86_64-win/OkumuLab 1.vst3` を同じ場所にコピーします（どちらか一方だけにしてください）。
- **スタンドアロン**：Releases の zip にある `OkumuLab 1.exe` を起動し、Options（左上）からオーディオ出力と MIDI 入力を選びます。
- macOS と Linux の入れ方は、それぞれの zip / tar.gz に入っている `README.txt` にあります（下の「macOS 版と Linux 版」も参照）。
- 画面には **WebView2 ランタイム**を使います（Windows 11 には標準で入っています）。ない場合はネイティブ画面で開きます。WebView2 の作業フォルダは `%APPDATA%\OkumuLab\OkumuLab 1\WebView2` です（作れないときは一時フォルダ）。環境変数 `OKL_NATIVE_UI=1` で、いつでもネイティブ画面にできます。
- Windows では、MIDI 機器を同時に開けるのは1つのアプリだけです。スタンドアロンと DAW を同時に起動しないでください。

## Gedackt 8'（v2.0.0）

2 つ目のストップです。木製の停管で、寸法は英国の Stopped Diapason（Dickson 1882）です（最初はドイツの細い型、Janke 2015 のハウスオルガンの Gedeckt 8' でした。下の「スケールの変更」）。寸法・切り上げ・端補正・壁の損失・木材は文献の式と値です。音を後から加工する処理はなく、音を合わせるために選んだ定数もありません。ただし栓の位置は、製作者と同じく、鍵盤の音程に合うところに置いています（下の「栓の位置」）。設計の前の調べものは、開発時の調査報告（Gedackt 8' の寸法・物理データ調査）にまとめました。

### ストップの切り替え

- 上のバーのメニュー（v1.1.1 までの実験レシピの場所）と DAW のプログラムで選びます。選ぶと**全部のつまみがそのストップの作ったままの値**になり、DAW にはつまみの変更として伝わります。
- RESET（上のバーと行ごと）とダブルクリックは、**使っているストップの初期値**に戻します。Prinzipal と違う初期値は Open/Stopped（100 %）、Scale（−9.44 HT）、Mouth width（円周の 0.2542）、Wall loss（×1.27）です。Ears と Arched cut-up の初期値は Gedackt でも 0 %（髭なし、まっすぐな切り上げ。Ears は使い手の整音で 100 % から 0 % にしました：下の「使い手の整音」）です。DAW から見たパラメータの初期値は Prinzipal のものです。
- 鍵を押したままストップを替えると、それまでの管は止まって消え（形はそのまま）、押している鍵が新しいストップで鳴り直します。
- ストップはプロジェクトに保存されます（パラメータ Stop）。1.x のプロジェクトのレシピ番号は使いません。
- 音域は両方のストップとも **MIDI 24〜96**（C, 〜c⁴）で、それより下と上の鍵は鳴りません。ch10 のパッドのパイプ（C〜c²）は音域の中です。

### 切り上げ：+5 半音にした理由

- Janke は「Gedackt は鳴る音の高さで正規の切り上げより 6〜9 半音高く切ると、らしく、よく鳴る」「風圧が低いと切り上げは 2〜3 半音下がる」と書いています。
- 最初は真ん中の +7.5 半音で作りました。このときプラグインの基準の風（Wind 1.00 = 500 Pa ≒ 51 mmWS）では、16' の高さのオクターブ（MIDI 24〜33）が発音を保てず、弱まって消えました。
- 500 Pa は Janke のハウスオルガンの風圧（40〜50 mmWS）とほぼ同じです。そこで同じ文献の低い風圧の規則を当てはめ、+7.5 − 2.5 = **+5 半音**にしました。
- 結果は C 37.9、c¹ 13.4、c³ 4.7 mm です。Janke 自身のハウスオルガンの Gedeckt 8'（C 35、c¹ 14、c³ 5.2 mm）と 1 割以内で合います（+8 %、−4 %、−9 %）。
- それでも最低音の C,（32.7 Hz）は発音の限界のすぐ上で、30 秒で 60 dB から 48 dB へゆっくり弱まります。Cut-up を ×0.90 にするか、風を強めると安定します（下の「前提と制限」）。

### 栓の位置（調律）

- Gedackt は栓の位置で調律します（Dickson 1882）。1/4 波長から端補正を引いた位置に栓を置いても、高い切り上げのジェットは遅く、音を下へ引くので、高音で最大 63 セント低く鳴りました。
- そこで、基準の状態（Wind 1.00、20 °C、Pitch lock 0 %）で各鍵がちょうど鍵盤の音程で鳴る位置に栓を置きます。その位置はモデル自身で鍵ごとに鳴らして求め、表 `src/dsp/KcalTableGedackt.inc` にしました（`labium_check kcalgen` が作ります。1/4 波長に対する倍率 0.991〜1.005。歌口の首を加えたときに作り直しました）。Prinzipal の音程の較正表 `KcalTable.inc` と同じ考え方です。
- 鳴った音を直す処理ではありません。管の長さ（栓の位置）だけを決めています。風・温度・気体などを変えれば、音程は物理どおりに動きます。

### 停管の管頭の計算の修正（Gedackt だけ）

- Open/Stopped の管頭は、開（反射 −1）と閉（+1）を周波数で分けて混ぜます。その分かれ目（クロスオーバー）は 5 Hz でした。基音が 33〜65 Hz の停管では、この段の位相の進みが基音にかかり、低音が最大 +277 セント高くなって、鳴りにくくなりました。Gedackt では分かれ目を 0.02 Hz にしました（基音で硬い栓との差は 1 セント以内）。
- 損失フィルタの当てはめと遅れの補正の基準を、開管の基音 c/2L ではなく、Open/Stopped に応じた基音（停管なら c/4L）にしました。
- Prinzipal はどちらも以前のままです。
- 画面に出す「鍵盤からの音程のずれ」と、変調マトリクスのソース「Pitch dev」の基準：鍵盤の音は、Prinzipal では開管の共鳴、Gedackt では停管の基音（開管の共鳴の 1/2）です。最初は Prinzipal と同じ基準のままで、予備のネイティブ画面が鍵盤どおりの Gedackt を「+1199 セント」と表示していました（スクリーンショットで見つけて直しました。音には関係しません）。

### 壁の損失

- 長方形の管の壁の損失は、周長と断面積の比で決まります（Rucz ら 2023、1/2Q ≈ Cδ/S）。モデルでは損失の半径を 2S/C = W·D/(W+D) にしました。幅 4：奥行き 5 では、断面積の等しい円管の 1.135 倍です。
- 木管の実測の Q は、滑らかな壁の計算より 18〜29 % 低くなります（平均で損失が 1.205 倍）。そのうち放射の分（最低共鳴の損失の 22.8 %）は壁と関係がありません。そこで壁の損失だけを (1.205 − 0.228) / (1 − 0.228) = **1.27 倍**にしました（Wall loss の初期値 ×1.27）。Prinzipal の初期値 2.5（手順1の値）とは意味の違う数字です。

### 新しい部品

- **側面の髭（Ears、VOICING）**：歌口の両側に立つ板です。歌口の空気の栓のうち両側の部分が、フランジのない端（端補正 0.6133 a）からフランジ付きの端（0.8216 a）になる、として端補正に加えます（その差を、歌口の周のうち両側が占める割合 H/(W+H) と、Fletcher & Rossing と同じ断面積の比 S/S_m で掛けます）。c¹ では音程が 9.1 セント下がります（栓の位置は髭のある状態で合わせてあります）。この「両側だけがフランジになる」扱いは私の置いた仮定で、髭の効果を測った文献は見つかっていません。
- **半円形の切り上げ（Arched cut-up、VOICING）**：上唇を歌口の幅の半円にし、その平均の高さを切り上げとします（歌口の面積と端補正はまっすぐな切り上げと同じ）。切り上げが低くて半円が入らない鍵では平たい半楕円にし、両端はジェットが広がり始める位置（3h + 7.67 b）より上に保ちます。ジェットは幅の方向に 4 本の帯に分かれて歌口を渡り、帯ごとに渡る時間・広がり・成長・ラビウムでの半幅とずれ・流量を持ち、ジェットの駆動はその和です。c¹ の第3倍音は −6.9 dB（まっすぐ）から −11.3 dB（半円）になり、音が丸くなります。Klais の修復報告に「半円形の切り上げ、側面の髭」とあるのに従いました。帯に分けた計算は私のモデルで、実測との比較はしていません。初期値は 0 %（まっすぐ）で、つまみを上げると半円に近づきます。
- **栓の位置の表**：栓は、作ったままの管（Arched cut-up 0 %、髭なし〈v2.0.0 の使い手の整音から。それまでは髭あり〉、基準の風）が鍵盤の音程で鳴る位置に置きます。Arched cut-up の初期値を 0 % にしたとき、この表（`src/dsp/KcalTableGedackt.inc`、`labium_check kcalgen`）を作り直しました。
- **栓の表示**：画面の 3D では、Open/Stopped を下げると、革を巻いた栓が管頭から少しずつ抜けていきます（0 % で管の外に出ます）。
- **栓を抜いたときの切り上げ**：Lab の Cut-up follow（初期値 100 %、Prinzipal と共通）は、切り上げを鳴る音の高さに合わせて動かします（整音数を保つ。W ∝ f^(−2/3)）。このため栓を抜くと c¹ の切り上げは 13.4 mm から 8.6 mm になり、管はオクターブ近くでよく鳴ります（74〜75 dB）。実際の管のように歌口をそのままにする（Cut-up follow 0 %）と、停管用の高い切り上げは開管には高すぎ（整音数が約半分）、ほとんど鳴りません（C〜c³ で 23〜33 dB、息の音。`labium_check gopen`）。
- **叩いた木管（Mallet）**：前板を、木目が管の長さの方向の直交異方性の板（板目：L が長さ、T が幅、R が厚さ）として、4 辺を単純支持で解きます。周波数は Leissa の式、ω = π²√((D₁₁(m/L)⁴ + 2(D₁₂ + 2D₆₆)(m/L)²(n/b)² + D₂₂(n/b)⁴)/(ρh))。幅の真ん中を叩くので n は奇数だけです。奇数×奇数のモードは単極として放射し、管内の空気の体積の変化で空気柱も鳴らします。マレットとのヘルツ接触は厚さ方向のヤング率 E_R とポアソン比 ν_RT で計算します。板厚は Rucz らの木管の板（幅 55.3〜69.8 mm に 10〜11 mm）の比、幅 × 10.5/61.8 です。
- **木材（Pipe wood、MALLET）**：ホワイトオーク（初期値）、レッドパイン、シトカスプルース、ウェスタンレッドシダー。Wood Handbook（FPL-GTR-190、5 章、含水率 12 %）の曲げのヤング率 +10 %（繊維方向）、E_T/E_L・E_R/E_L・G_LT/E_L・ポアソン比の表、密度は比重 × 1120 kg/m³ です。ホワイトオークの G_LT は表にないので、レッドオークの値を使いました。損失係数は同書の内部摩擦（対数減衰率で乾いた木 0.02〜湿った木 0.1）の幾何平均 0.0447/π を、すべての樹種・方向に使いました（樹種ごとの値は同書にありません）。

## Gedackt の音色の点検（v2.0.0）

「Gedackt らしくなく、Gamba っぽい」という指摘を受けて、寸法と物理モデルを点検しました（`labium_check gtimbre <鍵>`：第2〜第9倍音を、口の信号と声の出力 L+R で、つまみを一つずつ動かして並べる）。

- **修正：栓をした管頭が鳴っていた**。管の損失（壁と両端の放射）は管頭の反射にまとめて入れてあり、管頭の流れをその損失込みの反射から計算していたため、損失の分が「栓を通る流れ」になって放射されていました。c¹ で口より 22.5 dB 小さく、その中身は第3・第5倍音などの上の倍音が主でした。
  - 栓が入っているとき（Open/Stopped が 0 より大きいとき）は、管頭の流れを損失を含まない反射から求めるようにしました。完全に栓をした管頭は鳴りません（c¹ で −83 dB）。
  - 出力の倍音（dB re 基音）は次のように変わりました。

    | 鍵 | 倍音 | 修正前 | 修正後 |
    |---|---|---|---|
    | c¹ | 第3倍音 | −5.3 | −6.9 |
    | c² | 第3倍音 | −6.3 | −9.0 |
    | c² | 第8倍音 | −22.7 | −27.4 |

  - 開いた管（Open/Stopped 0 %）の計算式は前と同じで、Prinzipal の音は変わりません（同じ試験で数値が一致）。
  - `labium_check gedackt` に「栓をした管頭は鳴らない」を加えました。
- **寸法**：主な原因ではありませんでした。
  - c¹ の切り上げ 13.4 mm は Janke 自身の Gedeckt 8'（14 mm）とほぼ同じです。
  - 管の太さを ±4 半音、歌口の幅を 1/4 周まで変えても、c¹ の第3倍音は ±2 dB しか動きません。
- **残っていること 1：中音域の第3倍音が強い**。
  - c〜c¹ で −7 dB。Pykett が測った Stopped Diapason（中音域）は約 −15 dB です。
  - 強さを決めているのは、ジェットの振り切れ方です。c¹ では次のように変わります。
    - Jet feedback ×0.5：−21 dB
    - Labium offset 1 b：−13.6 dB
    - 切り上げ ×1.25：−14.8 dB
    - 切り上げ Janke の +7.5 半音（低い風圧の分を引かない）：−8.7 dB
  - ジェットの強さは、Prinzipal（手順1）の値をそのまま使っています。Labium offset の初期値も当時は Prinzipal の 0.5 b でした。後に、偶数倍音の問題のために 0 b にしています（下の「高音の偶数倍音と風道の長さ」）。
- **残っていること 2：高音の偶数倍音が強い**。
  - c³ で第4・第6・第8倍音が −22〜−25 dB で、奇数の第5倍音（−33 dB）より強くなっています。停管では偶数倍音は弱いはずで、原因は未解明です。
- **修正：Gedackt の歌口からの放射の損失**。歌口からの放射の損失を、歌口の面積（am = √(HW/π)）から計算していました。歌口は管と同じ体積流を出す点音源なので、放射する力 ρck²|U|²/8π は開口の大きさによりません（k·am ≪ 1 の間）。そのため損失は、管の等面積の半径 a の開口端と同じ 0.5 (ka)² になります。
  - Gedackt ではこれに直しました。第3倍音が 0.5〜0.8 dB 弱まります。
  - 放射の遅れが変わって高音が最大 4.6 セント低く鳴るので、栓の位置の表（`KcalTableGedackt.inc`）を作り直しました（`labium_check gtone` で c⁴ まで −3.5 セント以内）。
  - Prinzipal は手順1で合わせた音のままにするため、歌口の半径のままです（同じ扱いにするかは未決）。
- **足（Fuß）の長さ**：設計では全鍵とも 170 mm（Prinzipal の規則）で、高音の Gedackt では本体より長く描かれます。
  - モデルの足は、足穴と流路のあいだの空気の容積です。流路から出る流れは足の圧力だけで決まり、管の中の音とは結び付いていません。
  - そのため、足の容積を 1/10 にしても倍音は c¹・c³・c⁴ で ±0.4 dB 以内、立ち上がり 60 ms の足の圧力と音量もほぼ同じでした（`labium_check gtimbre`、OKL_ATTACK=1）。
  - 足の圧力の立ち上がりは、パレットが開く速さ（12 ms）で決まっています。
  - 音への影響はなく、見た目だけの問題です。
  - **描き方を実物に合わせました**。Bund Deutscher Orgelbaumeister の木製の停管（「Bauanleitung Holzpfeife」、J. Hess 2018）を基準にしました。
    - 元の管の寸法：内寸 47 × 60 mm、板厚 9 mm、Kern（ブロック）の高さ 50 mm（側板・裏板はその下面とそろう）、直径 18 mm の丸い足がブロックの下に 30 mm 出る、栓の高さ 50 mm、直径 14 mm の丸棒の取っ手が栓から 70 mm 出る。
    - これを内幅の比で、すべての鍵に同じ形で当てはめました。ブロックは内幅 × 1.06、足は × 0.64（太さ × 0.38）、栓は × 1.06、取っ手は × 1.49（太さ × 0.30）です。
    - 実物にない底板はやめ、取っ手は箱と横棒をやめて丸棒にしました。
    - 設計の足の長さ（足穴から歌口まで、`kGedacktFootPerWidth` = 80/47 × 内幅）にも同じ値を使います。C では 102 mm、c⁴ では 13 mm です（以前は全鍵 170 mm）。
    - 足の容積はこれに応じて小さくなります。上の測定のとおり、音には影響しません。
- 2 つの修正を合わせると、出力の第3倍音は c¹ で −5.3 → −7.4 dB、c² で −6.3 → −9.5 dB、c² の第8倍音は −22.7 → −27.6 dB になりました。

### 切り上げの鍵ごとの整音（試して取りやめ）

- C の第5倍音（−47.3 dB re 基音）に全鍵をそろえる切り上げの倍率を、モデルで鳴らして求めました（C,〜H, ×1.04〜1.11、c〜c⁴ ×1.18〜1.32）。
- 73 鍵が −46.8〜−49.1 dB にそろい、第3倍音も c〜c² で −16〜−17 dB になりました。
- 一方で、整音数は c¹ 1.18、c⁴ 1.10 まで下がりました。Wind ×0.7〜0.8 で中高音が鳴らなくなりました（規則どおりなら ×0.5 まで鳴る）。
- 使い手の判断で取りやめ、Janke の規則のままです。

### 歌口の板厚（実物の形との照合、v2.0.0）

木管の写真・断面図（胴、斜めに削った上唇、Kern、髭、切り上げ、Vorschlag、Kernspalte、足）と、モデル・描画を照らし合わせました。

- **合っていたこと**：
  - 歌口は内幅いっぱいで、幅 4：奥行き 5 の狭い面にあります。
  - 切り上げはまっすぐです。
  - Kern と Vorschlag の隙間が風道です。
  - 髭があり、足は丸い棒です。
- **抜けていたこと**：木管の歌口は前板（板厚 t）を貫いた穴で、両脇とキャップの上面が長さ t の短い首になります。
  - Fletcher & Rossing の端補正は薄い金属の壁の式で、この首の空気の質量が入っていませんでした。
  - Gedackt の歌口の端補正に、首の質量 ρt/S_m を管の長さに直した t·S/S_m を加えました（`mouthCorrection`）。
  - t は木の板の厚さ（内幅 × 10.5/61.8、Rucz ら）です。上唇は斜めに削られていて首は少し短いはずですが、使い手の選択で板厚ぜんぶを入れています。
  - c¹ では端補正が約 11 mm 増えます。栓はその分だけ下がり（胴が短くなり）、栓の位置の表も作り直しました。
  - 画面の描画（`engine-core.js`）も同じ式です。
  - Prinzipal は変わりません。
- **結果**（`labium_check gtone`、出力、dB re 基音）：

  | c | −8.1 | −10.1 | −28.6 | −32.8 |
  | c¹ | −7.4 | −11.0 | −24.7 | −32.5 |
  | c² | −9.5 | −15.4 | −30.0 | −41.4 |
  | c³ | −14.9 | −26.0 | −31.8 | −28.3 |
  | c⁴ | −29.7 | −26.9 | −25.5 | −26.9 |

  - 音程は全 7 鍵で ±1.4 セント以内、音量はほぼ同じ（−0.4 dB 以内）です。
  - 高音の偶数倍音は変わりません（c³ で第4 −24.3、第6 −21.5 dB）。第3倍音が弱まったので、c³ では偶数倍音のほうが目立つようになりました（下の「高音の偶数倍音」）。
- **描画**：上唇の斜めの削りは、まだ描いていません（板の切り口のまま）。

### 高音の偶数倍音と風道の長さ（調べた結果。モデルは変えていません）

- **高音の偶数倍音の原因**。次の 2 つが重なっています。
  - **偶数倍音の源**は、ジェットに対する上唇のずれ（Labium offset、初期値は 0.5 b でした。Prinzipal の手順1の値）です。
    - Fletcher & Douglas 1980 によると、偶数倍音の強さは上唇のずれでほぼ決まり、ずれ 0 では 0 になります。
    - モデルでもずれ 0 b では、c¹〜c⁴ で偶数倍音が −80 dB 以下になります。
  - **それを強めるのが、停管の上の共鳴が鋭く高いこと**です。
    - 歌口の端補正は集中した質量で、高音ほど胴の長さに比べて大きくなります（c³ で有効長 82 mm のうち約 20 mm）。
    - 質量の位相は高い周波数で頭打ちになるので、上の共鳴は奇数倍より高くなります。c³ では基音の 3.2、5.6、8.2 倍で、第6倍音が 3 番目の共鳴の近くに来ます。
    - 試しに質量をすべて遅延線に入れて（共鳴を整数倍にして）鳴らしました。偶数倍音は 10〜20 dB 下がりましたが、奇数倍音がずっと強くなりました（c³ の第3倍音 −1.2 dB、第5倍音 −7.9 dB）。
    - この共鳴のずれは実物にもあります。Pykett が測った木の停管（458 × 58 × 46 mm）では、共鳴の間隔が平均 355 Hz で、整数倍なら 286 Hz のところです。上の共鳴はモデルより大きく高くずれています。
  - **直したこと（使い手の指定）**：Gedackt の Labium offset の初期値を 0.5 b から **0 b**（上唇をジェットの中心の面に置く）にしました（`stopDefault`）。
    - 根拠は Fletcher & Douglas 1980 です。ずれ 0 で偶数倍音は消えます。また、木管と同じく長い風道を持つリコーダーは上唇がほぼ中央で、偶数倍音が弱く「うつろな」音です。
    - 栓の位置の表も作り直しました（変化は 1 セント未満）。Prinzipal の 0.5 b はそのままで、つまみでいつでも動かせます。
    - 結果（`labium_check gtone`、dB re 基音）：

      | 鍵 | 第2 | 第3 | 第4 | 第5 | 第6 | 音量 |
      |---|---|---|---|---|---|---|
      | C, | −62.7 → −101 | −28.7 → −14.5 | | −45.0 → −42.3 | | 59.0 → 64.3 dB |
      | C | −49.7 → −115 | −13.7 → −8.0 | | −53.2 → −26.6 | | 67.7 → 69.2 dB |
      | c¹ | −40.2 → −112 | −11.0 → −9.4 | −31.0 → −96 | −32.5 → −27.8 | −31.5 → −89 | 71.4 → 71.6 dB |

    - 偶数倍音は全鍵で −78 dB 以下になりました。
    - 奇数倍音は少し強まりました。最も大きいのは低音で、C の第3倍音が −13.7 → −8.0 dB です。C, も 5 dB 大きく鳴ります。
    - 音程は ±1.4 セント以内です。
  - **Bernoulli の項（Gedackt だけ、使い手の指定）**。
    - 上唇がジェットの中心にあっても、実物の停管には弱い偶数倍音があります。Fletcher & Douglas はその源を、ジェットの駆動の Bernoulli の非線形項だとしています。
    - 管に入るジェットの運動量が管を押す力は、Fletcher 1976（J. Acoust. Soc. Am. 60, 481、式 3）で (p_p − p_m) = ρ A (1 − A) Uj² です。A = S_j/S_p は、入るジェットが管の断面に占める割合です。
    - その非線形の部分 −ρ Uj² A² = −ρ (q_in/S_p)²（Fletcher の (Q)_III）を、Gedackt のジェットの駆動に加えました。静圧になる平均の分は、0.8 Hz の直流カットで除いています。
    - 線形の部分 ρ Uj² A は加えていません。モデルの駆動は Verge らの体積流の式で、手順1でその形のまま合わせてあるためです。
    - 栓の位置の表も作り直しました（−2.5 セント分）。Prinzipal は何も変わりません（項は Gedackt だけで働きます）。
    - 結果（`labium_check gtone`、dB re 基音）：

      | 鍵 | 第2 | 第4 | 第6 |
      |---|---|---|---|
      | C | −74.8 | −76.9 | −85.4 |
      | c¹ | −73.0 | −69.4 | −72.6 |
      | c³ | −73.2 | −69.7 | −69.3 |

    - 偶数倍音は全鍵で −67〜−80 dB です（項がないときは −78〜−119 dB）。奇数倍音と音程はほとんど変わりません（±1.6 セント以内）。
    - Fletcher & Douglas が書いているとおり、この項は普通のパイプでは小さく、偶数倍音は隣の奇数倍音より 40〜60 dB 弱いままです。Labium offset を動かすと、ずれによる偶数倍音がこれに加わります。
    - `labium_check gedackt` に「上唇がジェットの中心でも、c¹ の第2倍音が −90〜−50 dB で第3倍音より 40 dB 以上弱い」を加えました。
- **風道（Kernspalte）の長さ**。
  - 長い風道の出口は放物線形（Poiseuille）の流れになります。それを Bickley の形に当てはめると半幅は b = 2h/5 です（Verge ら。Ségoufin ら 2000 も参照）。モデルの出口の半幅 0.4 h は、この長い風道の値と同じです。
  - ジェットの進む速さは Fletcher の式（κ Uj^(2/3) (ωh)^(1/3)）で、これもこの形のジェットのものです。
  - 下流の広がり方は乱流の式（Thwaites & Fletcher）のままです。Fletcher & Douglas も、実際のフルー管のジェットはふつう乱流だと書いています。
  - 変えるべき点は見つかりませんでした。

### スケールの変更：Janke の細い型から Dickson の Stopped Diapason へ（v2.0.0）

- **原因の分析**（`labium_check gsrc`）：
  - 管に入る流れの倍音（ジェットの音源）は、どの鍵でも Fletcher & Douglas の式 1 + tanh(a sin ωt / b) どおりでした。上唇でのジェットの振れは、Janke の寸法で C 1.35 b 〜 c³ 3.6 b、Prinzipal と同じくらいです。
  - Gamba っぽさの元は管の側でした。音源の第3倍音を管がどれだけ持ち上げるかは、C で −8.0 dB（Prinzipal −12.0 dB）でした。
  - 停管の 2 番目の共鳴が、基音のほぼちょうど 3 倍（C で 3.007 倍、c¹ で 3.06 倍）にあり、第3倍音が共鳴の真上に乗っていました。
  - 歌口の端補正が 1/4 波長に比べて小さい（C 7 %、c¹ 15 %）ためです。細いスケールと高い切り上げで、管の比率が弦の系統に近くなっていました（Steenbrugge & De Baets：Lm/L ≈ 0.05 が弦、大きいほどこもったフルート）。
  - 同じ集中質量の歌口に Pykett の実測の 31 % を入れると、2 番目の共鳴は 3.40 倍になります（実測 約 3.5 倍）。物理の扱いは合っていて、寸法の違いだと分かりました。
- **変更**（使い手の指定。開発時の調査報告にあった、もう一つの文献の太さです）：
  - Dickson（1882）の英国の Stopped Diapason にしました。C の内寸 82.5 × 101.6 mm、テナー C 54.0 × 66.7 mm で、正規尺度より約 −9.4 半音です（Janke は約 −16.6 半音）。
  - 減り方は、この 2 つの寸法から 19.7 半音で半分です（本文の「18 番目の音で半分」ではなく、表の寸法を使いました）。
  - 切り上げは Janke の規則のまま（鳴る音の高さだけで決まる）です。風道・足穴・足は、等価直径から今までと同じ式で決まります（風道は後に実際の木管の幅へ変えました。下の「風道の幅」）。
  - 画面の描画（`engine-core.js`）も同じ寸法です。
- **一緒に直したこと**：
  - 切り上げの追従（Cut-up follow）の基準を、Gedackt では作ったときの共鳴（栓の位置の 1/4 波長、f0 / kcal）にしました（`baseParams` の `P_FDESIGN`）。
    - 以前は鍵盤の音 f0 が基準でした。栓の位置の倍率が 1 からずれる鍵では、作ったままの状態でも切り上げが動き、歌口の大きな端補正が縮んでいました。Dickson の寸法では、そのために高音が最大 41 セント高く鳴りました。
  - `labium_check kcalgen` を、0.1 セント以内に収まるまで最大 8 回繰り返すようにしました。
    - 端補正が 1/4 波長の半分近くになる高音では、栓を動かしても音程がその割合ほど動かず、2 回では合いきりませんでした。
  - 栓の位置の表の倍率は 0.997〜1.079 です。作ったままの音程は、全 25 鍵（3 鍵おき）で ±0.5 セント以内です。
- **結果**（`labium_check gscan`、出力、dB re 基音。前 → 後）：

### 音程が変わるときの「しゃくれ」（調べた結果。モデルは変えていません）

`labium_check gonset`（打鍵からの音程を 20 ms ごと。5 番目の引数 9 で基音だけ、4 番目の引数 −2 で離鍵後）で調べました。作為的な処理は見つかりませんでした。

- **前の音の余韻との重なり（主な原因）**：Gedackt は離鍵後の減衰が遅く、c で 100 ms 後 −10 dB、400 ms 後 −29 dB です（管の Q は約 57。Prinzipal の c¹ は 100 ms で −20 dB）。次の音が鳴り切るまでの 50〜90 ms は前の音のほうが大きく、音程が前の音から滑ってくるように聞こえます。
- **弱い打鍵での基音の立ち上がり**：基音だけを見ると、c で強さ 30 のとき −21 セント、127 のとき −6 セントから始まり、50〜90 ms で落ち着きます。打鍵の強さ → 弁の開く時間（4〜40 ms、Velocity sensitivity）で風圧の立ち上がりが遅くなるためです。この対応だけが、物理ではない決め方です。
- **立ち上がりの管の上の共鳴（チフ）**：停管の 2 番目の共鳴は 3 倍より少し上（c で 3.07 倍）にあり、音全体で測ると最初の 30〜50 ms は +20〜45 セント高く聞こえます。基音そのものは高くありません。
- 立ち上がりの衝撃（Start pulse）、ジェットの飽和、乱流ノイズを外しても、立ち上がりの音程は変わりませんでした。

## 調律（v2.0.0）

## 発音・励振メカニズムの見直し（v1.1.0）

寸法は Prinzipal なのに、音がガンバ（弦楽器系）やハーモニカのように鋭く、倍音の釣り合いが偏って聞こえる、という点を、発音・励振の物理（風道とエアジェット、ラビウム、管内の共鳴と放射）から調べて直しました。鳴った音を後から加工する処理（フィルタ・イコライザなど）は使っていません。変えたのはパイプの中の物理の式だけです。

### 調べたこと（手順1の物理に戻した音源、初期値、Wind 1.00、Pitch lock 0 %、残響なし、左右の耳ごと）

- c¹ の倍音（dB re 基音）：第2 −22.8、第3 −9.6、第6 −25.2、第8 −25.0、第10 −24.8、第12 −23.7。第6〜12倍音が平らに残り（第6〜12の合計 −18.3 dB）、弦楽器・ガンバの特徴です。c² では第10倍音（−19.5）が第4倍音（−28.1）より強く、第2倍音は −27.5 と弱く、奇数倍音が強い（ハーモニカ・クラリネット的なうつろさ）。
- 実際のプリンツィパル（Pykett の測定）：基音が最も強く、強い倍音は 4〜6 本、第5・第6倍音で約 −30 dB、その上は約 −24 dB/オクターブで落ち、第2倍音は低音ほど強くなります。
- ジェットの振れ（ラビウムからのジェットの中心のずれ ÷ ジェットの半幅）を測ると、c¹ で半幅の 6 倍、c² で 9 倍、C で 3 倍でした。

### 原因

1. **風道とエアジェット**：手順1のジェットはリコーダー型のモデル（Verge、Fabre）で、ラビウムでのジェットの幅を流路の出口の幅（半幅 0.4h）のままにし、擾乱の成長 exp(0.4 W/h) に e⁴ の上限をかけていました。オルガンパイプの歌口は流路の厚さの 7〜36 倍（c¹ で 18 倍）と長く、ジェットは渡るあいだに広がります（Thwaites & Fletcher 1983：オルガンのジェットは乱流の平面ジェットで、幅は距離に比例して広がる）。幅を出口のままにしていたため、ラビウムでジェットが半幅の 3〜9 倍も振れ、パイプに入る流れが矩形波のように全部入る・全部出るを繰り返していました。矩形の流れは奇数倍音と高い倍音を一様に出します。これがガンバ・ハーモニカのような音の主な原因です。
2. **ラビウム**：上唇のずれ（Labium offset）を流路の出口の半幅で測っていたので、初期値 0.5 b は c¹ で 0.13 mm でした。振れが半幅の 6 倍もあるとこのずれはほとんど効かず、偶数倍音（特にオクターブ）がほとんど出ませんでした。ラビウムでの剥離による渦の損失（(ρ/2)(u/0.6)²、Fabre & Hirschberg）と、反射・透過の式（歌口のイナータンス）は文献どおりで、変えていません。
3. **管内の共鳴と放射**：往復の損失を表す 1 次のフィルタは、基音・第3倍音・第9倍音の 3 点で合わせてあり、第9倍音より上では損失が頭打ちになっていました（c¹ の第16倍音で往復の利得 0.43、物理は 0.2）。上の共鳴が細いパイプのように鋭く残り、太いパイプ（プリンツィパル）らしく高い倍音が減りませんでした。放射の式 exp(−0.5(ka)²) も ka ≧ 1 では不正確です。

### 直したこと（すべて文献の式。定数は文献の値か手順1の値で、音を合わせるために選んだ値はありません）

1. **ジェットの広がり**：ジェットは出口から半幅 0.4h で出て、乱流の平面ジェットとして b = (x − 3h) / 7.67 で広がります（Thwaites & Fletcher 1983 の原点 x = 3h、Görtler の sech² 分布の係数 7.67）。中心の速度は運動量の保存で b^(−1/2) に下がり、ラビウムでは広がった分布を tanh で分けます（流れの式は手順1と同じ形）。ラビウムでの半幅は出口の、C で 10.7 倍、c¹ で 4.9 倍（1.26 mm）、c² で 3.2 倍、c⁴ で 1.3 倍です。
2. **擾乱の成長**：局所の成長率を μ = 0.16 / b とし、広がるジェットに沿って積み上げます（exp ∫μ dx）。出口では手順1の 0.4/h と同じで、オルガンパイプでの実測（Yoshikawa 1998：0.18〜0.26 mm⁻¹、流路 2.2 mm、0.4〜0.57/h）とも合います。広がるほど成長が遅くなるので、手順1の上限 e⁴ は不要になりました（c¹ で e^4.4、C で e^5.3、c⁴ で e^3.3）。
3. **Labium offset の単位 b**：「ラビウムに届いたジェットの半幅」にしました（文献の定義です。以前は出口の半幅で、ジェットが広がらないモデルでは同じものでした）。初期値 0.5 b は c¹ で 0.63 mm です。つまみの範囲（±2.5 b）と初期値は同じですが、±1.2 b くらいを超えるとジェットがエッジをまたがなくなり、パイプは鳴りません（以前は ±2 b くらいまで鳴った）。画面の mm 表示も新しい定義です。
4. **ニッキング**：刻みは、広がったジェットをさらに nk = 1 + 0.75 × Nicking 倍厚くします（流量は同じ）。手順1の「増幅 ∝ 1/b」は e⁴ の上限に隠れて低音・中音域では働いていなかったので、成長は広がるジェットのものを使います（そのまま入れると深い刻みでパイプが鳴らなくなる）。乱流・立ち上がりのパルス・エッジトーンの減り方は以前のままです。
5. **管の損失と放射**：1 次のフィルタは管壁の損失（境界層 × Wall loss）だけを受け持ち、管頭と歌口の放射は別の 2 次の段にしました。|H|² = 1 / (1 + x² + βx⁴)、x = ωτ、τ = √((1 − Open/Stopped) a² + a_m²) / c：低い周波数で 0.5(ka)² + 0.5(k a_m)² と一致し、β は x = 2 で Norris & Sheng（Silva ら 2009）の開口端の |R| に合わせます。アナログの 2 次の低域通過を双一次変換したもので、いつも安定・受動的です。20 kHz までの倍音で、物理の往復利得との差は初期値の全鍵で 0.064 以下です（c¹ の第16倍音：以前 0.43、今 0.22、物理 0.21）。
6. **画面**：ジェットの断面図と 3D の粒子は、歌口を渡るあいだに広がるジェットを描き、半幅 b はラビウムでの値を表示します。
7. **検査用の切り替え**：手順1のジェットと損失に戻す `Voice::phase1`（試験だけが使う）を残し、手順1の C コアとの一致の試験はそれで行います（音源の移植が正しいことの確認。プラグインでは使いません）。

### 変わらないこと・変わったこと

- **小さな振幅のふるまいは手順1の物理と同程度**：鳴り始める風は ×0.3 のまま。弱めると音程が下がり（c¹ で ×0.5 −15 セント、×0.3 −33 セント。手順1は −12、−31）、鳴らしたまま弱めると c で ×0.15、c¹ で ×0.22 まで鳴り続け、戻すときは c¹ で ×0.36、c で ×0.5 くらいまで鳴りません（ヒステリシス。手順1は c¹ ×0.27〜0.31、c ×0.42〜0.48）。強めると音程が上がります（×5 で C +15、c +18、c¹ +24、c² +36 セント）。つまみの音程への効き方（温度・音速・ガス・密度・切り上げ）も手順1とほぼ同じです。
- **オーバーブローしやすくなりました**（文献の整音数 3 を超えるとオーバーブローする、という方向）：切り上げ ×0.8 で C〜c が ×3.5、f♯〜c¹ が ×4.0、f♯¹ が ×4.5。×0.65 では C〜c が ×2.0、f♯〜c¹ が ×2.5、f♯¹ が ×3.0、c² が ×3.5 でオクターブに移ります（手順1は ×0.65 で C ×3.0、F♯ ×3.5、c ×4.5 だけ）。標準の切り上げでは 5.00 まで基音のままです。レシピ 3 と 13 の説明文を「c² から下」に直しました（値は同じ）。
- **音が 4〜7 dB 大きくなりました**（初期値で C −26.4 → −18.9 dBFS、c¹ −24.9 → −20.6 dBFS）。広がるジェットが周りの空気を巻き込み、ラビウムでの流量が増えるためです（物理どおり。出力のゲインは変えていません）。大きな和音で出力のリミッター（−1 dBFS）が働くときは、Output を −4 dB くらいにすると、見直し前（手順1の物理）と同じ音量です。公開版 v1.0.0 と比べると、同じ演奏（残響あり）で 2〜7 dB 大きく（c¹ +6.9、C・c・c² の和音 +7.2、7 音の和音 +6.3、c⁴ +2.2 dB）、v1.0.0 と同じにするには Output −6 dB くらいです。
- Pitch lock 100 % の精度は以前と同じです（全音域 0.05 セント以内）。

## 純粋な物理モデルへの戻し（v1.1.0）

- **理由**：v1.0.0 では「ビリビリ」の原因を v0.6.3 の音色（高音で上の倍音が平らに残る、オクターブが弱い）と考え、それを抑えるためにジェットと出力を調整しました（下の「Prinzipal の寸法の見直し（v1.0.0）」）。本当の原因はホストのブロック長の不具合（下の「ホストのブロック長によるビリビリの修正」）で、調整とは無関係でした。そこで調整をすべて取り除き、手順1の物理モデルに戻しました。
- **取り除いたもの**（v1.0.0 の 5 項目すべて）：
  1. 500 Pa での整音 → 手順1と同じ 75 mmWS（735 Pa）での整音（切り上げも手順1と同じ）
  2. ジェットが歌口を渡るあいだの広がり（レイノルズ数で 0〜0.04）
  3. 上唇でのジェットの振れの頭打ち（半幅の 2.5 倍）と、増幅の上限 e⁶ → 手順1の e⁴
  4. 上唇を届いたジェットの広がりの半分だけずらす、隠れたずれ（Labium offset のつまみはそのまま）
  5. 管頭の音を長さ × sin 27.5° だけ遅らせる道のりの差
- **残したもの**：ブロック長の不具合の修正、アプリと VST3 の計算モードの統一（v1.0）、起動画面のロゴ、GAS の点灯条件、試験用の切り替え。
- **Pitch lock の初期値は 0 %**（物理のまま、範囲は 0〜100 % のまま）。RESET、ダブルクリック、Pitch lock を指定しないレシピ（1 Prinzipal 8' など）もすべて 0 % です。100 % にすると、以前と同じく鍵盤の音程に保ちます。
- **確かめたこと**（48 kHz、残響なし、Pitch lock 0 %）：
  - 音源は v0.6.3 の音源と全サンプル一致します（11 鍵、Pitch lock 0 % と 100 %）。ブロック長にもよりません（`labium_check blocks`）。
  - 風圧：弱めると音程が下がり（c¹ で ×0.5 −12 セント、×0.3 −31 セント）、×0.2〜0.3 より下では鳴らなくなります（息の音だけ）。鳴らしたまま弱めると ×0.15 で −69 セント、戻すときも ×0.27 までは −50 セントのまま弱く鳴ります。強めると音程が上がり音が大きくなります（×5 で C +12、c +14、c¹ +21、c² +34 セント）。
  - つまみの音程への効き方（c¹）：温度 −30／80 °C で −154／+154 セント、音速 ×0.5／×2 で −1139／+1114 セント、ガス CO₂／ヘリウムで −413／+1761 セント、密度 ×0.2／×5 で +27／−50 セント、カットアップ ×0.4／×2.5 で −124／+122 セント。Jet feedback ×3 で音色が変わり（第2倍音 −35 → −44 dB）、Labium offset ±2.5 と Wave speed 0.6 ではパイプが鳴りません。
  - オーバーブロー：標準の切り上げでは Wind pressure の最大 5.00 まで基音のままです。切り上げを ×0.8 にすると C が ×4.5、×0.65 にすると C が ×3.0、F# が ×3.5、c が ×4.5 でオクターブに移ります（測った f♯・c¹・f♯¹・c²・c³ は 5.00 まで移りません）。
- **v1.0 から変わったこと**：音色は手順1のものに戻ります（c¹ で第2倍音 −9 → −25 dB、第6〜12倍音の合計 −31 → −19 dB。高音ほど上の倍音が強い）。初期状態の音程は物理のまま（風 1.00 で鍵盤の音から −2〜+6 セント）。

## macOS 版と Linux 版

- **形式**：macOS は VST3、Audio Unit、スタンドアロン（Apple silicon と Intel の両方で動く 1 つのバイナリ、macOS 10.15 以降、署名は ad hoc）。Linux は VST3 とスタンドアロン（x86-64、glibc 2.35 以降）。
- **ビルド**：`bash build.sh`（Windows の `build.bat` と同じ使い方。`bash build.sh dsp` は音源と labium_check だけ）。GitHub Actions（`.github/workflows/build.yml`）が、main と release/* への push のたびに macOS と Linux でビルドし、試験（labium_check の物理の項目、pluginval 厳しさ 10、macOS では Audio Unit の auval も）を行い、配布用の zip / tar.gz を作る（実行結果のページの Artifacts に 7 日間。サインインしてダウンロードする）。macOS では、Intel 用の半分も Rosetta 2 で labium_check の一部を実行する。`v<バージョン>` のタグを push すると、その 2 つを添付した Release の下書きを作る（本文は `packaging/RELEASE_NOTES.md`）。Windows 版の zip はこの PC でビルド・試験して `packaging/make_windows_zip.ps1` で作り、下書きに手で添付する。
- **CPU ごとの計算**：x86-64 は今までどおり SSE2 と AVX2+FMA（実行時に選択）。ARM64（Apple silicon、ARM の Linux）は同じ計算を素の C++ で書いた版（コンパイラが NEON にする）。浮動小数点のモード（丸めは最近接、例外はマスク、音声では非正規化数を 0 に）は `src/dsp/FpEnv.h` が x86-64 では MXCSR、ARM64 では FPCR で設定する。GCC / Clang では、ソースに書いていない積和の融合（FMA）をしない（`-ffp-contract=off`、MSVC の /fp:precise と同じ計算）。
- **画面**：Windows は WebView2、macOS は WKWebView（OS に入っている）、Linux は WebKitGTK（libwebkit2gtk-4.1、画面を開くときに読み込む。ない場合はネイティブ画面）。ページ（`web/`）は同じ。
- **Linux のスタンドアロン**：ALSA と JACK（PipeWire の JACK を含む。libjack は実行時に読み込む）。
- **未確認のこと**：macOS と Linux は GitHub のマシンでのビルドと試験（labium_check、pluginval、macOS では auval）まで。実際の Mac や Linux の PC で、音を聴いての確認や DAW での確認はしていない。

## ホストのブロック長によるビリビリの修正（v1.0 修正版）

- **症状**：SAVIHost（MME、44.1 kHz、バッファ 1764 サンプル）で鳴らすと、規準状態でもビリビリと鳴り、ピッチが +2.7 ¢ ほどずれ、管内の波形も乱れた。
- **原因**：パイプの計算は 32 サンプル（内部レート）ごとの制御フレームで係数を更新する。ジェットの揺らぎ（乱流）の前に置いたローパスの係数と、その遅れの補正値（と側孔の係数）だけがフレームをまたいで保存されておらず、1 回の計算呼び出しの途中でフレームが切れると、残りの部分は「ローパスなし・補正なし」で計算されていた。ジェットの遅れがそのたびに跳ぶので、雑音と音程のずれになる。
- **起きる条件**：ホストのブロック長が 16 の倍数でないとき（SAVIHost の 1764、441 など）、または鍵盤の音の始まりがブロック内の 16 サンプル単位の位置にないとき（ライブで弾いた MIDI は大半がこれ）。サンプルレートには関係しない。0.6.3 と別セッションの v1.0.0 の音源にも同じ箇所がある。
- **確かめたこと**：
  - SAVIHost の出力を録音し（WASAPI ループバック）、同じ条件（44.1 kHz、ブロック 1764）を DAW なしで再現すると、周期からのずれ −14 dB（正常は −35 dB）、倍音のあいだの成分 −18 dB re H1（正常は −42 dB）、6.25 Hz（1764 × 4 サンプル周期）の揺れまで一致した。
  - 直した版はブロック長（16、37、100、441、480、1764）によらず、持続音の出力が全サンプル一致する（`labium_check blocks`、44.1／48 kHz、側孔の開閉とも）。直す前の版ではこの検査が 480 以外で失敗する。
  - 16 の倍数のブロックで拍の頭から鳴らした音は、直す前と全サンプル同じ（その場合の音は変わらない）。
  - VST3 として読み込んで鳴らすと、直す前の VST3 は 44.1 kHz／1764 で −14 dB、48 kHz／480 でも音の始まりが 7 サンプルずれると −18 dB・+2.7 ¢。直した VST3 はどちらも −35〜−38 dB・0.0 ¢。
  - 以前 Bitwig で録った演奏でも、29 音のうち 14 音で倍音以外の雑音が 3 dB 以上多かった（5 音は 10 dB 以上）。Bitwig でのビリビリにもこの不具合が加わっていたと考えられる。
- 試験用：`okl_hosttest --render` は環境変数 `OKL_HOST_FS`・`OKL_HOST_BS` でホストのサンプルレートとブロック長を変えられる。

## アプリと VST3 の統一（v1.0）

v1.0 は、音源に上の v1.0.0 を採用した版です。v1.1.0 の音源は手順1のものに戻したうえで励振を見直しましたが、この節で統一した計算モードはそのまま使っています。

- **きっかけ**：Bitwig で鳴らすと初期状態でも「ビリビリ」と聞こえた件を、Bitwig の中で弾いた演奏を記録して調べました。Bitwig の中でプラグインが出していた音は、同じ演奏を DAW を通さずに音源で計算した音と一致し（平均 0.2 dB）、原因は Bitwig ではなく、そのとき入っていた版の音源（0.6.3 の音源：第2倍音が −26〜−41 dB と弱く、第6〜12倍音が強い）でした。同じ演奏をこの版の音源で鳴らすと第2倍音は −15〜+8 dB に戻り、第6〜12倍音は 6〜10 dB 下がります。
- **コード**：アプリ（`OkumuLab 1.exe`）と VST3 は同じソースから同時にビルドされ、物理モデル（`src/dsp`）とプラグインの処理（`processBlock`）は共通です。両者で違うのは、画面に出すホスト名と、試験モードの終わり方だけです。
- **実測**：試験用の切り替え `OKL_RENDERTEST=<記録したノート>|<出力 WAV>` で、アプリと VST3 のそれぞれが自分の `processBlock` で同じ演奏（Bitwig で弾いた 61 音、60.9 秒）を計算した結果は、**全サンプル一致**しました。プラグインの画面を開いているかどうかでも音は変わりません（一致）。
- **統一した点（浮動小数点の計算モード）**：ホストのスレッドが丸めの方式（MXCSR）を標準と違うものにしていると、同じ音源でも計算結果が変わりました（音源だけで −108 dB 程度）。音源の準備（パイプの設計・部屋の計算）、ブロックごとの処理（MIDI の処理を含む）、つまみの曲線の変換を、アプリと同じ計算モード（最近接丸め、例外はマスク、音声処理ではデノーマルを0に）で行うようにしました。標準のモードではアプリと VST3 は全サンプル一致し、ホストが一生を通して別の丸めを使った場合でも差は −110 dB 以下です（JUCE 自身が行う直線のつまみの換算の分）。
- **音は v1.0.0 と同じ**：同じ演奏を VST3 で鳴らした結果は、以前の v1.0.0 の VST3 と全サンプル一致します。
- 試験用：`okl_hosttest --render <記録> <出力> [vst3]`（記録したノートを VST3 で鳴らす）、環境変数 `OKL_HOST_ROUNDING`（プラグインを呼ぶあいだだけ丸めを変える）、`OKL_HOST_ROUNDING_ALL`（プラグインの生成から丸めを変える）。結果は `test_out/unify_v10.txt`。
- v1.0 のバージョン番号は 1.0.0 のままでした（画面の表示も v1.0.0）。

### ビリビリの原因

鍵盤全体（C〜c⁴ の 61 鍵、残響なし）の倍音と波形を測りました。

- **c¹ から上は方形波でした。** ジェットの振れが上唇で半幅の 5〜9 倍もあり、内と外へ弁のように切り替わっていました。第5〜12倍音がそれぞれ −20〜−25 dB で平らに残り、合計で基音の −13〜−19 dB です（実測のプリンシパルは 1 オクターブあたり約 −24 dB で落ちる）。リードやブザーのような音です。
- **オクターブ（第2倍音）がない。** 切り替わりが上唇に対してほぼ対称なので奇数倍音ばかりになり、さらに歌口と管頭の音を道のりの差なしに足していたため、両端で逆向きのオクターブが打ち消されていました（出力の第2倍音 −17〜−40 dB）。
- **低音のざらつき。** C〜F は倍音と雑音の差が 23〜29 dB しかなく、切り替わりのたびに乱流の雑音がまとまって出ていました。

### 変えたこと（音源の物理）

1. **整音の圧力を基準の 500 Pa にしました。** 切り上げは整音数（Ising）2.0（低音）〜2.4（高音）で 500 Pa から決めます。文献の範囲（1/3.4〜1/4）に入りました。
2. **ジェットは歌口を渡るあいだに広がります**：b = b0 + s x。広がりの速さ s はジェットのレイノルズ数 Re = U_j h / ν で決まり、Re 500 以下（層流、高音域）で 0、2000 以上で 0.04 です。基準の風で C は Re ≈ 1700、c³ は ≈ 650 です。気体や温度（粘性）、風圧でも変わります。
3. **上唇でのジェットの振れは、自分の幅の 2.5 倍で頭打ちになります。** 波の振幅が飽和するので、1 周期の中ではなめらかな波のままです。手順1の「増幅は e⁴ まで」の上限は、振れを抑えるものがほかになかったための仮のもので、e⁶（低音を 5〜15 倍まで駆動する上限）にしました。
4. **上唇は、届いたジェットの半幅の半分だけずらしてあります**（Labium offset の初期値 0.5 b0 に、広がりの半分 0.5 s W を加えた位置）。ジェットのパルスが非対称になり、プリンシパルのオクターブが出ます。Labium offset のつまみは以前と同じく上唇を mm で動かします（表示も同じ）。
5. **管頭の音は、管の長さ × sin 27.5°（残響の部屋の聴き手がオルガンを見上げる角度）だけ遅れて届きます。** 左右の混ぜ方（歌口 0.85・管頭 0.35 など）は手順1のままです。

s = 0.04、2.5 倍、半分という値は、文献の物理の範囲（層流と乱流の中間の広がり、振れは幅程度で飽和）の中で、プリンシパルの実測の音色（上の表）に合うように選びました。これらを 0 にし、整音の圧力を 75 mmWS、管頭の道のりの差を 0 にすると、v0.6.3 の音（手順1のモデル）にそのまま戻ります（試験の port と tone で使っています）。

## Wind pressure（v0.6.1）

- MIDI CONTROLLER のつまみ 5「Wind pressure」は、それまでの **Bellows（ふいご）パラメータ**です（DAW のパラメータ ID は ``bellows``、名前は「Wind pressure」）。WIND 欄から Bellows はなくなり、Trem rate と Pallet speed の 2 つになりました。
- 値は **0.00〜5.00**、**1.00 = 500 Pa**（風箱の圧力 = 500 Pa × 値）。初期値は 1.00 です。DAW には「1.00 (500 Pa)」と表示し、「600 Pa」と入力しても受け付けます。
- つまみの動き：**0.00〜1.00 はつまみの最初の 2/3 で、以前の Bellows（0〜1.5 を直線）と同じ速さ**です。1.00〜5.00 は残りの 1/3 で、等比（同じだけ回すと同じ倍率）です。
- 以前の mmWS の「Wind pressure」パラメータ（10〜1000 mmWS）はなくなりました。基準の 500 Pa は固定です。
- コントローラー：つまみ 5（CC93）、フェーダー 1（CC82）、エクスプレッションペダル（CC11）がこのパラメータを動かします。パッド A1（風圧 ×5）とパッド B（風のパイプ）は以前のままです。マトリクスの行き先「Wind pressure」もこのパラメータです。
- パイプは 75 mmWS = 735 Pa = 1.47 で整音してあります（手順1・v0.6.x と同じ。v1.0.0 は基準の 1.00 = 500 Pa で整音していましたが、v1.1.0 で戻しました）。緑の帯はバロック期のオルガンの例 69〜97 mmWS = 1.35〜1.90 です。
- 0.6.0 で保存したプロジェクト：Bellows の値はそのまま（同じ数値）読み込まれ、mmWS の Wind pressure の値は無視されます。
- レシピの風の値は新しい目盛りに直しました（2：0.43、4：1.00 → 5.00、19：2.16）。最大の 5.00（2500 Pa）では標準の整音のパイプはオーバーブローしないので、レシピ 3 と 13 は風 5.00 に加えて歌口を低く切り（カットアップ ×0.65）、オーバーブローさせています（v1.1.0 では c² から下。手順1の物理では c から下、v1.0.0 は C〜c² の全体）。

### 変調マトリクス

4つのスロットがあり、それぞれ「ソース × 量」で1つのつまみを動かします。量はそのつまみの**目盛りの全幅に対する割合**です（+100 % でソースが 1 なら、スライダーの端から端まで）。

- ソース（11）：ベロシティ、鍵（c¹ = 0、±4 オクターブで ±1）、LFO 1・LFO 2（正弦）、エンベロープ（ノートごと：アタック後に減衰）、モジュレーションホイール（CC1）、プレッシャー（チャンネル／ポリ・アフタータッチ）、**パイプ自身の状態**＝音量（40〜100 dB SPL）、**オーバーブロー**（上の倍音で鳴っている）、**音程のずれ**（鍵盤から ±50 セント）、ランダム（ノートごと）。
- 行き先（27）：風圧、カットアップ、上唇位置、スケール、開管↔閉管、気体、温度、トレムラント、歌口の幅、乱流、足穴、グライド、側孔、音速、密度、FM の深さ・比、ジェットの帰還、クロスドライブ、波の速さ、エッジトーン、立ち上がりのパルス、ニッキング、壁の損失、打点、ダンパー、管壁の厚さ。
- **パイプごと**に計算します（ベロシティ、鍵、エンベロープ、音量、オーバーブロー、音程のずれはそのパイプのもの）。64 サンプルごとに目標を更新し、パイプは約 12 ms でなめらかに追従します（オーディオレートの変調は物理FM が受け持ちます）。
- 例：**Overblow → Open/Stopped +100 %**（計画の「オーバーブローした瞬間に閉管へモーフする」）。強い風でオーバーブローした瞬間に管頭が閉じます。試験では c（MIDI 48、Wind pressure 5.00・カットアップ ×0.65）でオーバーブローの検出 1.00、管頭は 100 % 閉じました。

### 最適化

- **AVX2 + FMA**：叩いた管壁のモード（最大 64 個の複素回転）を 4 つずつ計算します。この PC（Ryzen 5 3500U）で SSE2 の **1.5〜1.6 倍**、結果の差は 1e-15 です。残響の周波数領域の積和も AVX2 にしましたが、メモリ帯域で決まるため、この PC ではほとんど速くなりません（0.97〜1.09 倍）。CPU は起動時に一度だけ調べます（環境変数 `OKL_NO_AVX2=1` で SSE2 に固定）。

## Mallet モード

パイプの胴を硬いマレットで叩くモードです（WIND / MALLET で切り替え。DAW のパラメータ Excitation）。すべて物理モデルです。

- **管壁**：Flügge のシェル方程式（3×3）と梁関数で、円筒の曲げ・楕円・呼吸モードを求めます。材料は 5 種類（30 % 錫のコモンメタル、50 % のスポッテッドメタル、75 % 錫、亜鉛、銅）で、ヤング率・密度・内部損失は材料表から。管内外の気体による付加質量と放射（ベッセル関数）、熱弾性減衰を含みます。
- **マレット**：頭は 5 種類（硬いゴム、アクリル、ツゲ、真鍮、毛糸）。ヘルツ接触と Hunt–Crossley の減衰で、接触時間と力が速さ・材料・大きさで決まります。ベロシティ = マレットの速さ（0.1〜3 m/s）。
- **毛糸（Yarn、v2.0.0）**：ゴムの芯に毛糸を巻いた頭です。羊毛は弾性球のヘルツ則（F ∝ x^1.5）に従わず、F = K x^p（p は 2.5 前後）に従います（Stulov 1995, Proc. Estonian Acad. Sci. Eng. 1(2) 172–182：実測のハンマーで p = 1.5〜3.5、彼のフェルトのモデルで 2.5）。K と p は、膜を叩くフェルトのマレットの値 **K = 1.6×10⁸ N/m^2.54、p = 2.54** を使いました（Bilbao, Torin & Chatziioannou 2015, Acta Acustica united with Acustica 101, 155–173 の図 12。Rhaouti, Chaigne & Joly 1999 のティンパニのマレットによる）。羊毛は管壁よりはるかに柔らかいので、壁の側のへこみは入れていません。Hunt–Crossley の減衰は p によらず同じ式です。25 mm の頭が 1 m/s で硬い壁に当たるときの接触時間は、式で約 4.5 ms（硬いゴムは約 0.8 ms）です。そのため高い倍音が出にくく、柔らかい音になります。`labium_check mallet` に接触時間の確認を、`host_test` に硬いゴムより暗い音になることの確認を加えました。
- 毛糸の頭の値のうち、次の 3 つは文献にないので私が決めました：K は頭の大きさによらず同じ（大きさの法則が文献にない）、損失なし（e = 1。元の文献のモデルも損失なし。フェルトのヒステリシス、Stulov 1995 JASA は入れていません）、質量は頭の大きさの球をゴムの芯の密度（1150 kg/m³）で（毛糸の巻きの密度が文献にない）。
- Mallet head の選択肢は最後に Yarn を足したので、v1.x と v2.0.0 の既存の設定の番号（0〜3）はそのままです。DAW のオートメーションを 0〜1 の値で書いている場合は、位置がずれます。
- **空気柱**：管壁の呼吸が管内の空気を押し、管の共鳴（WIND と同じ導波管）も鳴ります。
- 鍵を離すとフェルトのダンパーが当たります（Damper、ペダルで保持）。叩いたパイプに効かないつまみ（風・ジェット関係）は画面で薄くなります。側孔は空気柱に効きます。
- 試験：材料ごとの減衰、接触時間、打点と節、つまみの効き方（風・ジェットのつまみは変化ゼロ、管・材料・マレットのつまみは変化）を確認しています。32 本を同時に叩くと、最初の 1 秒はこの PC の 1 コアの 60〜100 % です（測ったときの PC の状態で変わります。打った直後の接触の計算が重く、鳴っているあいだはずっと軽くなります）。

### モードの打ち切りをやめた（v2.0.0）

- **見つけたこと**（使い手：Gedackt の MALLET、特に毛糸で、途中から急に叩いた音が変わる。`labium_check gmal`）：
  - 管壁・前板のモードは、「12 ÷ 接触時間 [Hz]」より上を計算に入れていませんでした（`Mallet.cpp` の `design`、`designBox`）。接触時間は、実際の打鍵の速さではなく、いつも 1 m/s で見積もっていました。計算を軽くするための打ち切りで、物理ではありません。
  - 毛糸の頭では上限が 2.7 kHz です。Gedackt の前板は、鍵が高いほど細くモードが高くなります。c¹ ではいちばん低いモード（2604 Hz）が残りますが、d¹ では一つも残りません。出だし 50 ms の音量が、隣の鍵どうしで −28.1 → −51.2 dB と崖になっていました。
  - 硬いゴムでは g#³ → a#³（−20.8 → −48.1 dB）、Prinzipal の真鍮では a#³ → c⁴（−52.5 → −94.1 dB）に同じ崖がありました。
  - 1 回の打音の中では、音は滑らかに減衰していました（25 ms ごと）。
- **変えたこと 1：打ち切りをやめた**：
  - 聴こえる範囲（20 kHz、サンプリング周波数の 0.45 倍まで）のモードを、すべて候補にします。どのモードがどれだけ鳴るかは、毎サンプル解いている接触の力が決めます。
  - 64 個の上限は残しました。候補が 64 個を超えるのは、Gedackt の C, 〜A#, と Prinzipal の大きい管だけです（`labium_check gcand`：Gedackt は C から上で全部のモードが入ります）。その順位づけには、今までどおり接触時間の見積もりを使います。
- **変えたこと 2：押されているあいだの板の放射**：
  - 打ち切りをやめると、毛糸の高音ほど音が大きくなりました（C, −39 dB → c⁴ −17 dB）。調べると、モードの放射を「そのモードが自分の周波数で自由に鳴っている」ときの式（変位 × ω²）だけで出していました。
  - マレットがゆっくり押しているあいだ、共鳴よりずっと低い周波数で押されるモードは、力にそのまま付いて動きます。このとき放射は加速度で決まり、ほとんど出ません。それなのに古い式は、押す力そのものを、面密度だけで決まる大きさで放射していました。
  - 放射の反応部分（加速度に比例する部分）に、モードの運動方程式の力の項 −φF/M を入れました（`oF`）。自由に鳴っているあいだ（力 0）は、今までと同じです。
- **結果**（出だし 50 ms、打鍵の強さ 100、残響なし。前 → 後）：
  - Gedackt の毛糸：C, −38.2 → −50.7、C −34.6 → −51.7、c¹ −28.1 → −51.9、d¹ −51.2 → −51.2、c² −56.7 → −57.2、c³ −76.0 → −80.6 dB。崖はなくなり、c¹ 付近から高音へ滑らかに弱まります（小さく硬い前板は、柔らかい頭ではほとんど揺れません）。
  - Gedackt の硬いゴム：低音は同じ（C, −18.6）。c¹ −22.4 → −28.4、c³ −20.9 → −36.8、a#³ −48.1 → −49.8 dB。
  - Prinzipal：c¹ より下はどの頭でも 0.3 dB 以内で同じです。高音は、崖があった頭で大きく変わります（真鍮 c³ −40.2 → −29.5、c⁴ −94.1 → −32.6 dB、アクリル c⁴ −36.2 → −32.4 dB）。

## 風圧と音量（WIND モードの物理の見直し）

非常に弱い風でも大きく鳴る、という問題を直しました。原因は、ジェットが歌口を渡る時間が一定のままで、弱い風で別の（エオリアン的な）発振が大きく鳴ってしまうことでした。実際のジェットは乱流で、渡る時間に揺らぎがあります。これを入れました（**渡る時間の標準偏差 0.35 τ**、7 タップのガウス平均）。

- 結果（c¹、ピッチロックなし、手順1のジェットで測定）：5 mmWS で 31 dB（息とかすかな音）、20 mmWS で 63.9 dB、75 mmWS で 71.6 dB。風圧が 2 倍で約 +3 dB という実測（Verge 1997）に沿っています（v1.0.0：5 mmWS 41 dB、20 mmWS 64.7 dB、75 mmWS 70.8 dB）。
- 回帰チェック（`labium_check wind` の 2c）：プラグインと同じ音源全体の経路・ピッチロック 100 % で、5 mmWS が 75 mmWS より 20 dB 以上小さいこと、風とともに単調に大きくなること、風圧 2 倍あたり 1.5〜6 dB であることを確かめます。揺らぎのない以前のジェットではこのチェックに落ちることも、同じ試験の中で確かめています。

## 残響（物理的な部屋）

電子的に聞こえた FDN の残響をやめ、**教会の身廊を計算したインパルス応答**のたたみ込みにしました。

- 部屋：長さ 34 m・幅 16 m・高さ 16 m。西のギャラリーにオルガン、身廊の中ほどで 0.6 m 間隔の無指向性マイク 2 本。壁・窓・床（会衆席）・天井の吸音率は帯域ごと。
- 初期反射：鏡像法（周波数で変わる吸音、散乱 0.3、ISO 9613-1 の空気吸収）。後部残響：Eyring の T60 を帯域ごとに求め、拡散音場のエネルギー密度（4πc/V）で STFT 合成。左右のマイクの相関は sin(kd)/kd。
- T60：63 Hz 5.7 s、125 Hz 4.9 s、250 Hz 4.1 s、500 Hz 3.4 s、1 kHz 3.1 s、2 kHz 2.7 s、4 kHz 2.2 s、8 kHz 1.1 s。最初の反射 5.3 ms、残響音／直接音 +7.8 dB。
- たたみ込みは 4 段の分割（64・256・2048・4096 点）で遅延なし。CPU は 1 コアの約 2〜3.5 %。DAW に知らせるテール長は 6 秒です。

## 前提と制限

- **側孔はピッチロックで消えません**（上の「側孔とピッチロック」）。側孔の音程をなくしたいときは側孔を OFF にします。
- オーバーブローする風圧は音域と切り上げで違います。標準の切り上げでは Wind pressure の最大 5.00（2500 Pa）まで基音のままです。切り上げを ×0.8 にすると C〜c が 3.5、×0.65 にすると C〜c が 2.0、c² が 3.5 でオクターブに移ります（ピッチロックなし。レシピ 3 と 13 は ×0.65）。文献では整音数が 3 を超えるとオーバーブローするとされ（標準のパイプは 75 mmWS で整音数 2.0〜2.4、5.00 では 3.7〜4.4）、v1.1.0 で近づきましたが、標準の切り上げではまだ文献よりオーバーブローしにくい可能性があります。
- **Labium offset の b は v1.1.0 から「ラビウムに届いたジェットの半幅」**です（c¹ で 1.26 mm。以前は流路の出口の半幅で 0.26 mm）。同じ目盛りでも mm では大きく、±1.2 b くらいを超えるとジェットがエッジをまたがず鳴りません。v1.0.0 で作った設定を開くと、上唇の位置（mm）が変わります。
- **出力は手順1の物理（見直し前）より 4〜7 dB 大きい**です（広がるジェットが周りの空気を巻き込むため、物理どおり）。大きな和音で出力のリミッター（−1 dBFS）が働く場合は Output を下げてください。
- Pitch lock の初期値は 0 % です。風圧・温度・音速・気体・密度・切り上げなどで音程が物理どおりに動きます。演奏で鍵盤の音程に保ちたいときは 100 % にします（MIDI CC85、フェーダー 3）。
- 音域は MIDI 24〜96 です（v2.0.0）。それ以外の鍵は鳴りません。
- **Gedackt の最低音 C,（32.7 Hz）は発音の限界のすぐ上**です。基準の風では 30 秒で 60 dB から 48 dB へゆっくり弱まります。Cut-up を ×0.90 にするか、風を強めると安定します。
- Gedackt の栓を抜いた音は、Cut-up follow 100 %（初期値）で切り上げが音の高さに合わせて低くなるので鳴ります。歌口を切ったままにする（0 %）と、ほとんど鳴りません（上の「Gedackt 8'（v2.0.0）」）。
- **Arched cut-up を上げると、Gedackt は 1 本あたり Prinzipal の約 1.7〜2 倍の CPU** を使います（半円形の切り上げのジェットを 4 本の帯で計算するため）。初期値の 0 % では Prinzipal と同じくらいです。
- 側面の髭の効果（両側だけがフランジになる扱い）、半円形の切り上げの帯への分け方、木の損失係数（全樹種・全方向で同じ値）、ホワイトオークの G_LT（レッドオークの値）は、私が置いた仮定です（上の「Gedackt 8'（v2.0.0）」）。毛糸のマレットの K が頭の大きさによらないこと、損失がないこと、質量の密度も同じく仮定です（上の「Mallet モード」）。
- クロスドライブは 64 サンプル（48 kHz で約 1.3 ms）遅れて伝わります（空気を伝わる時間程度）。
- マトリクスは 64 サンプルごとの更新です（なめらかに補間）。オーディオレートの変調は物理FM を使ってください。
- CPU：ジェットの揺らぎ（弱い風を正しくするために入れたもの）の分だけ、手順4より 1 ボイスあたりの負荷が 1〜2 割増えました。32 音を全部鳴らし続けると、この PC の 1 コアの約 4 割（手順1の物理での測定、電源の状態で変わります）です。
- 音色は v1.1.0 の物理（広がるジェット、両端の放射）によるものです（c¹ で第2倍音 −18 dB、第6〜12倍音の合計 −28 dB。手順1の物理では −23 dB・−18 dB）。第2倍音は Pykett の測定の範囲では弱めの側です。強いオクターブが欲しいときは Labium offset を上げます（+1.00 b で c¹ −12 dB）。
- 乱流ジェットの広がり（b = (x − 3h) / 7.67）のうち、x = 3h からの直線的な広がりと中心速度の下がり方は Thwaites & Fletcher がオルガンの流路の模型で測った乱流ジェットのもの、係数 7.67 は乱流平面ジェットの古典値（Görtler）です。実際のパイプでは流路の形（面取り、ニック）や風圧でジェットが層流のまま長く進むこともあり、その場合はこのモデルより振れが大きく、明るい音になります。
- 成長率 μ = 0.16 / b は、出口での値（手順1と Yoshikawa の実測）を、ジェットの幅に反比例させて下流へ延ばしたものです。広がったジェットの成長率を直接測った値ではありません。
- **ジェットの帰還（Jet feedback）を最大近く（×1.9 以上）にして風をごく弱く（100 Pa 前後）すると**、ジェットのループが振り切れ、安定化処理がボイスをリセットし続けることがあります（0.6.0 のランダム総当たり 240 回のうち 1 回。0.6.1 の総当たりでは起きませんでした）。出力は有限で止まりますが、プツプツした音になります。Lab の極端な組み合わせです。
- 巨大な管（音域外の低音）は、壁の損失が小さいと離鍵後も十数秒以上鳴り続けます（物理どおり、ゆっくり減衰します）。
- この PC では画面の 60 fps は安定しません（ホスト試験で平均 53 fps。バッテリー駆動では約 32〜35 fps）。音は画面を待たないので、途切れません。
- DAW と MiniLab 3 での確認は、上のチェックリストで行います。

## 手順1〜4からの変更点

| 変更 | 理由 |
|---|---|
| ピッチロックのサーボ | 鳴っている音程を各ボイスが測って管長を補正します（整律表の代わり）。オーバーブローや閉管では、その倍音を鍵盤の音程に合わせます。側孔があるときは、その分ずれた共鳴の位置で聴きます（v0.6.0） |
| 離鍵後の処理 | 極端な設定で「離鍵後も鳴り続ける」原因（ジェット速度の下限、足部の √ 流量則、渦損失の遅れ）を、離鍵後と不安定な領域だけ直しました |
| 損失フィルタの上限 | 極端な設定での発振を防ぐ上限（通常は働きません） |
| ジェットの揺らぎ（v0.6.0） | 弱い風での音量を物理に合わせるため（上の「風圧と音量」） |
| v1.0.0 の整音の圧力・ジェットの広がりと振れの頭打ち・上唇の位置・管頭の道のり | v1.1.0 で取り除き、手順1のとおりに戻しました（上の「純粋な物理モデルへの戻し（v1.1.0）」） |
| ブロック長の不具合の修正（v1.0） | 32 サンプルの制御フレームの係数（ジェットの揺らぎのローパスと側孔）を、計算の呼び出しをまたいで保つ。手順1の計算そのものは変わりません |
| Pitch lock の初期値（v1.1.0） | 0 %（手順1は 100 %） |
| ジェットの広がりと成長（v1.1.0） | 手順1はラビウムでのジェットの幅を流路の出口のままとし、成長に e⁴ の上限をかけていました。乱流の平面ジェットとして広がり（Thwaites & Fletcher 1983）、成長率がその幅に反比例するようにしました（上の「発音・励振メカニズムの見直し（v1.1.0）」） |
| Labium offset の単位（v1.1.0） | ラビウムに届いたジェットの半幅（手順1では出口の半幅。広がらないモデルでは同じもの） |
| 管の損失と放射（v1.1.0） | 手順1の 1 次のフィルタは壁の損失だけにし、両端の放射を Norris & Sheng の |R| に合わせた 2 次の段にしました（第9倍音より上で損失が頭打ちにならない） |
